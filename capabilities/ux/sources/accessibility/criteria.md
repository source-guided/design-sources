# Access and operation

- Can relevant users perceive the necessary content and distinctions?
- Can they find and operate the controls with the supported input methods?
- Are content, state and instructions understandable?
- Are roles, names, values and changes exposed appropriately to the supported assistive technologies?
- Which original standards apply to this control and situation?
