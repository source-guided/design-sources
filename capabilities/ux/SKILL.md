# Design source entry

This is an internal capability of the selected design source. Its [reference entry](../../references/index.json) exposes the judgment areas and their supporting sources.

The model selects relevant questions and makes decisions from the user's task and actual evidence. This source supplies questions, applicable quality constraints and references; it does not supply a product brief, a default screen or an execution sequence.
